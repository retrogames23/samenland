# Leitstern

Spieler sehen ein Dorf, um das sie sich gekümmert haben, über Jahre zu einer blühenden Stadt heranwachsen

## Kennzahl

Schulzen, die täglich eine Entscheidung für ihr Dorf treffen (ein Ereignis entschieden, ein Gebäude gekauft, eine Aufgabe erfüllt)
